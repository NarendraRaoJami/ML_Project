Student Performance Predictor

Analyze how different factors influence a student's academic performance using Machine Learning

📊 Project Overview

This Machine Learning application predicts student test scores based on multiple real-world factors. The model helps understand how socio-economic and educational variables impact performance.

🧠 Features Used

  • Gender
  • Ethnicity
  • Parental Level of Education
  • Lunch Type
  • Test Preparation Course

⚙️ Tech Stack

  • Python & Machine Learning
  • Flask Web Framework
  • HTML & CSS
  • Scikit-Learn
